# Review session

A Review session pairs a document with a focused feedback workflow.

## Structure

- Document canvas
- Annotation list
- Decision controls

## Interaction

Move between annotations without forcing a full page reload of context.

:::warning
Do not bury the original document behind review chrome. The text remains the source of truth.
:::
