# Word page

A Word page is the long-form reading surface for a single document.

## Structure

1. Title and metadata
2. Reading body
3. Related context and references
4. Actions such as review or share

## Interaction

Keep primary actions quiet until the reader needs them. Reading comes first.

:::accessibility
Preserve heading order, provide a table of contents for long pages, and keep focus visible when jumping between sections.
:::

:::best-practice
Reuse foundation tokens for measure, type, and spacing so every Word page feels like the same book.
:::
